# 老後資金チェック

5つのステップに数字を入れるだけで、**退職するときに必要な金額**と、**今のペースで足りるか**が分かるツールです。
ブラウザだけで動きます。サーバーもログインも不要です。

公開ページ: https://fuku-sim.github.io/rougo/

## 5つのステップ

1. 家族と年齢（退職する年齢・何歳まで計算するか）
2. 老後の収入（ねんきん定期便の額面×手取り率、退職後に働いた収入、その他の収入）
3. 老後の生活費（指定の年齢から生活費が下がる設定つき）
4. 老後の大きな出費（車・配車サービス・リフォーム・旅行・子や孫への援助・医療・介護など）
5. 今の資産と貯め方（積立・退職金・利回り・物価）

## 結果

- 退職時に必要な金額と、準備できる見込み額、その差
- 不足するときは「積立を月いくら増やせば届くか」「生活費を月いくら下げれば届くか」
- 年齢ごとの資産の推移と、資産が尽きる年齢

金額はすべて今のお金の価値（物価上昇を除いた額）です。年金は物価ほど増えない仕組み（マクロ経済スライド）を考慮し、今の約82%で下げ止まる想定にできます。

## 含まないもの

運用益の税金、NISAと課税口座の区別、配偶者が亡くなった後の年金の変化は計算に含みません。

## プライバシー

入力内容はこのブラウザの中（localStorage）にだけ保存され、外部には送信されません。
